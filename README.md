# SeaBattle ⚓

Небольшая 3D-реализация классической игры **«Морской бой»**, разработанная на **Unity и C#**.
Проект поддерживает игру против ИИ, локальный режим на одном устройстве, несколько уровней сложности, настройки звука и качества графики, а также разные варианты UI для desktop, mobile и tablet.

> Учебный/дипломный проект. Репозиторий содержит исходный Unity-проект.

## Возможности

- игровое поле **10×10** для каждого участника;
- ручная и автоматическая (**Shuffle**) расстановка кораблей;
- проверка корректности положения кораблей и пересечений;
- пошаговая стрельба с визуальным снарядом и эффектами попадания/промаха;
- определение повреждения и полного уничтожения кораблей;
- победное состояние и визуальная индикация результата;
- режимы игры на одном устройстве и против ИИ;
- **3 уровня сложности ИИ**;
- регулировка громкости музыки и звуков;
- 6 уровней качества графики;
- отдельные элементы управления для desktop и мобильных устройств;
- поддержка `Screen.safeArea` для устройств с вырезами и нестандартными областями экрана;
- 3D-окружение с водой, отражениями, частицами и визуальными эффектами.

## Игровая логика

### Поле

Поле создаётся скриптом `GridGenerator`. Размер задаётся константой `10`, поэтому генерируется **100 клеток** на каждого участника.

```text
10 × 10 = 100 клеток
```

Каждая клетка представлена компонентом `Tile` и связана с состоянием корабля, попаданием и принадлежностью хода.

### Корабли

Корабли представлены отдельными prefab'ами (`Ship1`, `Ship2`, `Ship3`, `Ship4` и др.). Скрипт `ShipGrid` отвечает за:

- проверку положения;
- обнаружение пересечений с другими кораблями;
- привязку корабля к клеткам;
- количество жизней/сегментов;
- получение урона;
- определение полного уничтожения;
- возврат корабля в последнюю корректную позицию.

При автоматической расстановке `GameController` создаёт набор кораблей и случайным образом распределяет их по игровому полю.

### Стрельба

При выстреле создаётся снаряд. Попадание или промах определяется в момент столкновения с целевой клеткой.

Условная последовательность выглядит так:

```text
Выбор клетки
    ↓
Запуск снаряда
    ↓
Столкновение с Tile
    ↓
Проверка наличия корабля
    ↓
Попадание / промах
    ↓
Обновление состояния корабля
    ↓
Проверка победы
    ↓
Передача хода
```

## Искусственный интеллект

Логика ИИ находится в `AI.cs`.

Проект использует **3 уровня сложности**:

- **Уровень 1** — выбор допустимой клетки без целенаправленного продолжения после попадания.
- **Уровень 2** — после попадания ИИ может сосредоточить дальнейшие выстрелы на текущем повреждённом корабле.
- **Уровень 3** — используется более агрессивный вариант поиска цели, дополненный вероятностным поведением.

Ключевая идея ИИ — после успешного попадания получать соседние доступные клетки через `Tile.GetShootTiles(...)` и ограничивать область следующего поиска.

## Настройки

В игре предусмотрены:

- громкость музыки;
- громкость звуковых эффектов;
- качество графики от **Very Low** до **Ultra**;
- сохранение настроек через `PlayerPrefs`.

Параметры сохраняются между запусками игры, поэтому пользовательский выбор не сбрасывается после перехода между сценами.

## Поддержка устройств

Тип устройства задаётся через `GameSettings`:

```text
Desktop
Mobile
Tablet
```

На desktop используется отдельный набор UI-элементов и поддерживается клавиша `Escape` для паузы. На мобильных устройствах применяется другой интерфейс управления.

`SafeAreaFilter` автоматически адаптирует `RectTransform` к системной безопасной области экрана, что особенно важно для смартфонов с вырезами и закруглёнными углами.

## Установка и запуск

### Требования

Для открытия проекта рекомендуется использовать:

```text
Unity 2022.3.62f3
```

### Шаги

1. Клонируйте репозиторий.
2. Откройте папку проекта через **Unity Hub**.
3. Используйте совместимую версию Unity — `2022.3.62f3`.
4. Откройте сцену `Assets/Scenes/Initialization.unity`.
5. Запустите проект кнопкой **Play**.

## Управление

### Desktop

- **Левая кнопка мыши** — взаимодействие с игровым полем / UI.
- **Escape** — открыть или закрыть паузу.
- **X** — скрыть часть подсказок desktop-интерфейса во время игры.

### Mobile / Tablet

Используется сенсорное взаимодействие с адаптированным UI.

## Build

Проект можно собрать через стандартный интерфейс Unity:

```text
File → Build Settings
```

Перед сборкой рекомендуется убедиться, что нужные сцены входят в список Build Settings и порядок сцен соответствует логике запуска проекта.

## Авторская часть

Основная игровая логика реализована на **C#** с использованием компонентов Unity и событий игрового движка. Проект организован вокруг нескольких специализированных компонентов, что позволяет отдельно отвечать за игровое состояние, клетки поля, корабли, ИИ, аудио и пользовательский интерфейс.
